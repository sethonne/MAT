Polynomial Interpolation

Newton's Divided Differences Calculator

Interactive learning tool for polynomial interpolation using divided differences.

Definition

Newton's Divided Differences is a recursive method for constructing the unique polynomial of degree ≤ n that passes through n + 1 distinct data points \((x_0,y_0),\ldots,(x_n,y_n)\).

Key Vocabulary

\(x_i\) Nodes — all nodes must be distinct: \(x_i \neq x_j\) for \(i \neq j\). \(f[x_i]\) Zeroth-order DD — the function value \(f(x_i)=y_i\). \(f[x_i,x_j]\) First-order DD — slope of the secant through two points. \(f[x_i,\ldots,x_k]\) Higher-order DD — defined recursively below.

Recursive Formula

\[f[x_i,\ldots,x_j]=\frac{f[x_{i+1},\ldots,x_j]-f[x_i,\ldots,x_{j-1}]}{x_j-x_i},\quad i\neq j\]
Uniqueness: Given \(n+1\) points with \(x_i\neq x_j\) for \(i\neq j\), there exists exactly one polynomial of degree \(\le n\) interpolating them.

Newton Form Formula

The interpolating polynomial in Newton form uses nested basis polynomials built from the nodes:

\[\begin{aligned}P_n(x)&=f[x_0]\\&\quad+f[x_0,x_1](x-x_0)\\&\quad+f[x_0,x_1,x_2](x-x_0)(x-x_1)\\&\quad+\cdots\\&\quad+f[x_0,\ldots,x_n]\prod_{j=0}^{n-1}(x-x_j)\end{aligned}\]

Compact Form

\[P_n(x)=\sum_{k=0}^{n}f[x_0,\ldots,x_k]\prod_{j=0}^{k-1}(x-x_j)\]

Applications

Data Curve Fitting.

Interpolating a smooth curve through specific discrete control points.

Estimating Missing Values.

Approximating the value of a function at intermediate points where measurements are unavailable.

Numerical Analysis.

Foundation for numerical differentiation and integration (Newton-Cotes formulas).

Video Game Development.

Animation systems use polynomial curves to interpolate between keyframe poses. Physics engines fit polynomials to terrain heightmaps so vehicles follow hills smoothly — exactly what this tool's car demo demonstrates. Camera paths, particle trajectories, and shader gradients all rely on the same principle: sample a few control points, recover the polynomial, evaluate at every frame.

Spotlight: Video Game Terrain

A 2-D side-scroller needs a hill. An artist defines a few height samples \((x_0,h_0),\ldots,(x_n,h_n)\). Newton's method builds \(P_n(x)\) through those samples; the game evaluates it thousands of times per second to determine ground height at any position.

Mini Example — 3-point terrain

Control points: \((0,2),\;(3,5),\;(6,1)\)

\[f[x_0,x_1]=\tfrac{5-2}{3-0}=1,\quad f[x_1,x_2]=\tfrac{1-5}{6-3}=-\tfrac{4}{3}\]

\[f[x_0,x_1,x_2]=\tfrac{-\frac{4}{3}-1}{6-0}=-\tfrac{7}{18}\]

\[P_2(x)=-\tfrac{7}{18}x^2+\tfrac{5}{2}x+2\]

Data Input Guidelines

Properly format your coordinates and inputs for the interactive data table.

Guideline Description
Distinct \(X\) Values All \(X\) coordinates must be unique: \(x_i\neq x_j\) for \(i\neq j\). Divided differences require non-zero denominators.
Numerical Constants Inputs should be resolved numerical constants (e.g., 2.5).
Function Sampling To interpolate a function like \(\sin(x)\), manually sample discrete points and input them.
